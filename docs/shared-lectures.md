# المحاضرات المشتركة

## ما تم تنفيذه

### 1. البرنامج التحضيري (كل الكليات)
- محاضرة **واحدة** للكل الطلاب المسجّلين على «البرنامج التحضيري» في أي كلية.
- **الكلية المستضيفة:** كلية العلوم الصحية — فصل «ربيع 2025-2026».
- **الموعد:** الأحد 10:00–12:00 (قابل للتعديل من لوحة مواعيد الشعبة).
- **الشعبة المستضيفة:** `class_sections` باسم «مشتركة» (ID يظهر بعد التشغيل).
- يُسجَّل الطلاب تلقائياً في الشعبة المستضيفة ويُزالون من شعب مكررة لنفس المادة.

### 2. الكيمياء الحيوية + اللغة الطبية (العلوم الصحية + الطب العام)
- نُسخت المادتان إلى **كلية الطب العام** — السنة الأولى / الفصل الثاني (إن لم تكونا موجودتين).
- محاضرة مشتركة مستضافة من **كلية العلوم الصحية** لكل مادة.
- مواعيد افتراضية (قابلة للتعديل):
  - الكيمياء الحيوية: الثلاثاء 14:00–16:00
  - اللغة الطبية: الخميس 10:00–12:00
- في **الطب العام** تُنشأ شعبة «مرآة» بنفس المواعيد (للعرض في الجدول)؛ **الدخول للجلسة المباشرة** عبر الشعبة المستضيفة.

## أوامر الصيانة

```bash
php artisan shared-lectures:sync
php artisan shared-lectures:sync --group=prep_program
php artisan shared-lectures:sync --dry-run
```

يُفضَّل تشغيل `shared-lectures:sync` بعد:
- قبول تسجيلات جديدة على مواد مشتركة
- بدء فصل دراسي جديد
- تعديل مواعيد الشعبة المستضيفة (ثم إعادة المزامنة لنسخ المرآة)

## الإعداد

`config/shared_lectures.php` — مفاتيح المجموعات، الكلية المستضيفة، المواعيد الافتراضية.
